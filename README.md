# GUNDAM DGh — Premium Gunpla Store

Website bán Gundam/Gunpla giao diện premium, chạy hoàn toàn bằng HTML, CSS và JavaScript.

## Chạy trên GitHub Pages
1. Upload `index.html`, `style.css`, `script.js` lên repository.
2. Vào **Settings → Pages**.
3. Chọn **Deploy from a branch**.
4. Chọn branch `main` và folder `/ (root)`.
5. Save.

Website có:
- Responsive desktop/mobile
- Tìm kiếm sản phẩm
- Lọc HG/RG/MG/MGEX
- Sắp xếp theo giá
- Chi tiết sản phẩm
- Giỏ hàng lưu bằng localStorage
- Thêm/xóa/tăng giảm số lượng
- Form đặt hàng mô phỏng
